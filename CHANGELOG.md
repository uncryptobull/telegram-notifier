# Changelog

## 0.2.0

- Portable Windows application with no console dependency.
- Monitor, Account, and Settings tabs with native Windows controls.
- System tray menu, explicit exit, and single-instance protection.
- Separate account connection and contact selection.
- Independent notification tests and configurable event intervals.
- Optional name hiding and a sample-data preview.
- Automatic connection recovery and cancellable sign-in.
- Encrypted profiles, optional credential persistence, and session revocation on sign-out.
- Automated tests and Windows build configuration.
